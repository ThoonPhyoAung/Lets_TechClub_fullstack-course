PART 1: Global Setup & Theme System (Light / Dark Mode)

၁။ HTML (index.html)

  - <html lang="en" data-theme="light">: JS မ run ခင်ကတည်းက Light Mode ကို
    Default ဖြစ်နေစေဖို့နဲ့ Flash မဖြစ်အောင် ထည့်ထားပါတယ်။
  - <meta name="viewport" content="width=device-width, initial-scale=1.0" />:
    ဖုန်း (360px) နဲ့ Tablet (768px) တွေမှာ Responsive မှန်မှန်ကန်ကန် ပြဖို့
    မဖြစ်မနေ လိုပါတယ်။
  - <script src="js/main.js" defer></script>: HTML တွေ အရင်ဖတ်ပြီးမှ JS ကို run
    ခိုင်းတာမို့ DOM element မတွေ့တဲ့ Error ကို ကာကွယ်ပေးပါတယ်။
  - <a class="skip-link" href="#main-content">: Keyboard (Tab) သုံးသူတွေ Navbar
    ကိုကျော်ပြီး Main content ဆီ တန်းခုန်နိုင်အောင် ထည့်ထားပါတယ်။

၂။ CSS (css/style.css)

  - :root, [data-theme="light"] & [data-theme="dark"]: CSS Variables (--bg-page,
    --text-primary, --accent) တွေ ခွဲထားခြင်းဖြင့် data-theme ပြောင်းလိုက်တာနဲ့
    တစ်မျက်နှာလုံး အရောင်အလိုအလျောက် ပြောင်းစေပါတယ်။
  - *, *::before, *::after { box-sizing: border-box; }: Padding နဲ့ Border
    ကြောင့် Box width ကျော်ထွက်ပြီး Horizontal scroll မဖြစ်အောင် ထိန်းပေးပါတယ်။
  - html { scroll-behavior: smooth; scroll-padding-top: 6rem; }: Smooth scroll
    ဖြစ်စေပြီး Sticky Navbar အောက်မှာ Section title မဖုံးသွားအောင် 6rem
    နေရာချန်ပေးပါတယ်။
  - [hidden] { display: none !important; }: HTML hidden attribute ပါတဲ့ element
    တွေကို CSS flex/grid တွေက မကျော်နိုင်အောင် သေချာဖျောက်ပေးပါတယ်။
  - :focus-visible: Keyboard Tab နဲ့ ရွှေ့တဲ့အခါမှ Focus outline ပေါ်စေပါတယ်။

၃။ JS (js/main.js)

  - "use strict";: Variable ကြေညာဖို့ မေ့တာမျိုးလို Beginner အမှားတွေကို
    ကာကွယ်ပေးပါတယ်။
  - getSavedTheme() & saveTheme() + try/catch: Browser Private mode (သို့)
    Storage ပိတ်ထားချိန် Script crash မဖြစ်အောင် try/catch ခံထားပြီး Empty
    ဖြစ်နေရင် "light" ကို Default ပြန်ပေးပါတယ်။
  - initThemeSwitcher(): data-theme, aria-pressed, aria-label, Icon (🌙/☀️),
    Label (Dark/Light) တွေကို Sync လုပ်ပေးပါတယ်။

PART 2: Floating Glass Pill Navbar & Accessible Mobile Menu

၁။ HTML (index.html)

  - .site-header > .container > .nav-pill: Navbar ကို မျက်နှာပြင်အပြည့်မကပ်ဘဲ
    Floating pill ပုံစံ ဖွဲ့စည်းထားပါတယ်။
  - .desktop-nav: Desktop (>= 768px) မှာပြမယ့် Navigation links (About, Skills,
    What I Do, Projects, Contact)။
  - #menu-toggle: aria-expanded="false" နဲ့ aria-controls="mobile-menu" ပါပြီး
    Screen reader တွေကို ဘယ် menu ကို ထိန်းချုပ်နေလဲ ပြောပြထားပါတယ်။
  - #mobile-menu: စစချင်းမှာ hidden attribute ထည့်ထားပါတယ်။

၂။ CSS (css/style.css)

  - .site-header: position: sticky; top: 1rem; z-index: 100; pointer-events:
    none; (Pill အပြင်ဘက် ဘေးနေရာလွတ်တွေကို နှိပ်ရင် Page content ကို
    နှိပ်လို့ရနေအောင် pointer-events: none ထားပြီး .nav-pill နဲ့ .mobile-nav ကို
    pointer-events: auto ပြန်ပေးထားပါတယ်)။
  - .nav-pill: border-radius: 9999px;, background-color: var(--nav-pill-bg);
    (rgba(255, 255, 255, 0.25)), backdrop-filter: blur(10px); (အဖြူပေါ်မှာ အဖြူ၊
    အရောင်/Dark ပေါ်မှာ #869DA4 မှန်ကြည်လို မြင်ရစေတဲ့ Sister-style glass
    effect)။
  - @media (min-width: 768px): Desktop ရောက်တာနဲ့ .desktop-nav ကို ပြပြီး
    .menu-btn နဲ့ .mobile-nav ကို ဖျောက်ပေးပါတယ်။

၃။ JS (js/main.js)

  - setMenuState(isOpen): mobileMenu.hidden = !isOpen, aria-expanded,
    aria-label, Icon (☰/✕) ကို တစ်နေရာတည်းက ထိန်းချုပ်ပါတယ်။
  - Link Click Close: Mobile nav link တစ်ခုနှိပ်ပြီး Scroll ဆင်းတာနဲ့ Menu
    အလိုအလျောက် ပြန်ပိတ်ပေးပါတယ်။
  - Escape Key Close: Escape နှိပ်ရင် Menu ပိတ်ပြီး Focus ကို #menu-toggle ဆီ
    ပြန်ပို့ပေးပါတယ်။
  - Resize Reset: Window ကို >= 768px အထိ ချဲ့လိုက်ရင် Mobile menu
    ပွင့်ကျန်မနေအောင် ပြန်ပိတ်ပေးပါတယ်။

PART 6: Contact Info, Validated Demo Form & Footer

၁။ HTML (index.html)

  - #contact:
      - .contact-rows: Clean divider rows (Real mailto: link, GitHub, LinkedIn,
        Location) + Demo ဖြစ်ကြောင်း ရှင်းလင်းချက်။
      - <form id="contact-form" novalidate>: Browser default popup အစား
        ငါတို့ရဲ့ Custom JS validation ကို သုံးဖို့ novalidate ထည့်ထားပါတယ်။
      - Input တိုင်းမှာ aria-describedby နဲ့ #name-error, #email-error,
        #message-error (role="alert") ချိတ်ဆက်ထားပါတယ်။
      - #message-count: Live character counter (0 / 500 characters (min 20))။
      - #form-status: role="status" + hidden attribute။

၂။ CSS (css/style.css)

  - .form-control.is-invalid: Error ဖြစ်ရင် Border အနီ + Soft red background
    ပြပေးပါတယ်။
  - .field-error:empty { display: none; }: Error မရှိချိန် နေရာလွတ် မယူထားအောင်
    ဖျောက်ပေးပါတယ်။
  - .char-count.is-over: စာလုံး 500 ကျော်သွားရင် အနီရောင် Bold ပြပေးပါတယ်။

၃။ JS (js/main.js)

  - Validation Rules:
      - Name: .trim().length >= 2
      - Email: /^[^\s@]+@[^\s@]+\.[^\s@]{2,}$/
      - Message: .trim().length ဟာ 20 မှ 500 ကြား
  - Error UX:
      - Submit နှိပ်ချိန် မမှန်တဲ့ field တွေဘေးမှာ Error ပြပြီး ပထမဆုံး
        အမှားရှိတဲ့ field ကို .focus() လုပ်ပေးပါတယ်။
      - User က Error ဖြစ်နေတဲ့ field ထဲ စာပြန်ပြင်ရိုက်လိုက်တာနဲ့ input listener
        က Error ကို ချက်ချင်း ဖျောက်ပေးပါတယ် (Clear error on fix)။
      - အားလုံးမှန်ပြီး Submit လုပ်ရင် "Demo only. Your message has not been
        sent." ပြပြီး Form reset + aria-invalid ရှင်း + Counter ကို 0 / 500
        ပြန်ချပေးပါတယ်။

- [ ] Message ထဲ စာရိုက်တိုင်း 0 / 500 counter တက်နေရမယ် (501 ကျော်ရင်
  အနီပြရမယ်)။
- [ ] Field တွေကို အမှန်ပြင်ရိုက်လိုက်တာနဲ့ အနီရောင် Error ချက်ချင်း
  ပျောက်သွားရမယ်။
- [ ] Valid data နဲ့ Submit နှိပ်ရင် "Demo only. Your message has not been
  sent." ပေါ်ပြီး Form ပြန်ရှင်းသွားရမယ်။

၄။ Git Branch, Pull Request & Merge Workflow (Assignment Rule)

1.  Feature branch ဖွင့်ပြီး စစ်ထားတာတွေ Commit လုပ်ပါ-
    git checkout -b feature/ux-and-js-features
    git status
    git add index.html css/style.css js/main.js assets/avatar.png
    git commit -m "Implement floating glass navbar, UX redesign, and interactive JS features"
2.  GitHub မှာ Dedicated repo အသစ်တစ်ခု ဖန်တီးပြီး origin ချိတ်ကာ Feature branch
    ကို Push လုပ်ပါ-
    git remote add origin <YOUR_GITHUB_REPO_URL>
    git push -u origin main
    git push -u origin feature/ux-and-js-features
3.  GitHub Web ပေါ်မှာ feature/ux-and-js-features -> main ဆီ Pull Request (PR)
    ဖွင့်ပါ၊ Diff တွေကို Review လုပ်ပြီး Merge Pull Request နှိပ်ပါ။
4.  Local မှာ main ကို ပြန်ဆွဲယူပြီး Screenshots + README.md ကို နောက်ဆုံး
    commit/push လုပ်ပါ-
    git checkout main
    git pull origin main
