# Personal Portfolio & Projects

A personal developer portfolio showcasing web applications and embedded IoT hardware/software projects, deployed from the `portfolio` directory of the `Lets_TechClub_fullstack-course` repository.

## Project Overview

The `portfolio` folder showcases selected projects across web development and embedded IoT systems—including **MakerHub MM**, **Stationery Store Django POS**, **ESP32-S3 Smart Water & Motor Control**, and **Smart Motor Control System**—along with direct contact details and an interactive contact form.

## Features

- **Project Filtering & Carousel:** Filter projects by category (`All`, `Web Apps`, `Embedded IoT`), view live project counts (`#projects-count`), and scroll smoothly through project cards.
- **Responsive Layout:** Built to adapt across mobile, tablet, and desktop screens.
- **Contact Form Validation:** Includes real-time input feedback, character count tracking (`20–500 characters`), error messages, and form reset on submission.
- **Footer & Navigation:** Clean footer layout with quick return-to-top navigation.
